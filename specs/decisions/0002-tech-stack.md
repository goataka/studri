# 0002 技術スタック

- **上位ページ**：[決定の記録](README.md)
- **状態**：採用
- **決定**：[技術スタック](../tech-stack.md)のとおりにする

## 理由

- **型**：型で書ける制約は型で表す。AIが変更しても、型の検査で誤りを見つけやすい
- **LTS**：Node.js 26 は2026年10月にLTSになり、サポートが最も長い
- **依存を少なくする**：アプリは操作が中心で、画面も少ない。フレームワークなしで足り、読み込みも小さい
- **ビルド**：Vite はマルチページと TypeScript に対応し、Vitest と設定を共有できる
- **既存を活かす**：pnpm、Playwright、playwright-bdd、GitHub Pages は今のものを使い続ける
- **レビューの記録**：同じアカウントでは PR を承認できないため、コミットのステータスを使う

## 選ばなかった案

- **React や Vue**：依存と読み込みが大きくなる。今のアプリの規模では利点が少ない
- **Astro**：Markdown からページを作る用途に強いが、アプリは操作が中心で、その利点を使わない
- **JavaScript のまま**：型の検査がなく、AIの変更の誤りを見つけにくい
- **Biome**：自動チェックルールが prettier を指定している
- **GitHub Actions でエージェントを動かす**：API の費用がかかり、オーナーの判断が必要になる
