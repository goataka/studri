# 決定の記録

仕様や運用を決めたり変えたりした理由を残す。
AIが後から同じ議論をくり返さないようにする。

- **上位ページ**：[アプリの仕様](../README.md)

## 書き方

- **ファイル**：1つの決定を1ファイルにし、`NNNN-名前.md` とする
- **項目**
  - 状態：採用、置き換え済み
  - 決定：決めたこと
  - 理由：そう決めた理由
  - 選ばなかった案：検討した別の案と、選ばなかった理由
- **変更**：決定を変えるときは、新しい記録を作り、古い記録の状態を「置き換え済み」にする
