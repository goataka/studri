## 実行環境

- **Node.js**：26 LTS
  - サポート：2029年4月まで
  - 指定：`.node-version` と `package.json` の `engines`
- **パッケージ管理**：pnpm。採用済みのものとロックファイルを維持する
- **言語**：TypeScript。アプリと、検証や生成のスクリプトの両方に使う

## アプリ

- **形**：静的サイト。UIのフレームワークは使わない
- **ビルド**：Vite 8 のマルチページ構成
  - 出力：`dist/`。コミットしない
- **共通部品**：`apps/shared/` に置き、どのアプリも使う
  - 出題と採点
  - ヒントの出し方
  - 合格と復習
  - ふりがなの付与
  - 学習記録の保存と読み替え
- **コンテンツのデータ**：`curriculum/` と `specs/` の Markdown を、ビルド時に読み込んで型付きのデータにする
  - 生成物：コミットしない
- **学習記録**：ブラウザーの localStorage に保存する。形にバージョンを付け、古い形を読み替える

## 検証

- **単体テスト**：Vitest 5
  - 対象：出題と採点、合格と復習、ふりがな、学習記録の読み替え
- **E2E テスト**：Playwright と playwright-bdd。今のものを使い続ける
- **アクセシビリティ**：@axe-core/playwright
- **系統と仕様の検査**：`scripts/` の TypeScript を Node.js で直接実行する
  - 系統：前提、学年の順、循環、学習指導要領の項目の網羅
  - 仕様：対応表とコースの一致、表記の決まり
  - 生成：対応表とヒントのページを系統から作り、差分があれば失敗させる
- **Lint と整形**：[自動チェックルール](https://github.com/goataka/agent-rules/blob/main/rules/lint.md)に従う
  - Markdown：markdownlint-cli
  - ワークフロー：node-actionlint
  - 秘密情報：secretlint
  - 整形：prettier
  - TypeScript：ESLint と typescript-eslint
  - コミット前：husky と lint-staged

## CIと公開

- **基盤**：GitHub Actions
- **PR の検証**：品質ゲートをすべて実行する。ローカルと同じ `pnpm` のスクリプトを使う
- **公開**：main への反映でテストの環境に、release への反映で本番に公開する。どちらも `dist/` を gh-pages ブランチの自分の場所に置く。本番の公開のあとは、本番で E2E の確認を実行する
- **監視**：毎日、本番の確認と courses-of-study の変更の確認を実行し、問題を Issue にする
- **依存関係**：Dependabot で更新する。公開から7日たった版だけを使う
- **ワークフローの依存**：`.github/workflows/actions.lock` で固定する
- **自動マージ**：ブランチ保護で必須チェックを指定し、通った PR を自動でマージする

## AIエージェント

- **実行**：Claude Code のスケジュールされたタスクで、役割ごとに別のタスクとして動かす
  - 計画：週1回
  - 作成とレビュー：1時間ごと。作業がなければ何もしない
  - 監視：毎日
  - 改善：月1回
- **指示**：[AGENTS.md](../AGENTS.md) と、役割ごとのスキルを `.github/skills/` に置く。スキルには仕様への参照だけを書く
- **レビューの結果**：コミットのステータス `ai-review` として記録し、必須チェックにする
  - 理由：作成とレビューが同じアカウントで動くため、PR の承認は使えない
- **停止**：リポジトリの変数 `AUTOMATION_PAUSED` が `true` のとき、すべてのタスクとワークフローは何もしない

## 移行

- **アプリ**：今の JavaScript のアプリは、次に手を入れるときに TypeScript と共通部品に移す。まとめて書き換えない
- **スキル**：`studri-app-creator` の要件は仕様に移し、スキルには仕様への参照だけを残す
- **Node.js**：`copilot-setup-steps.yml` の Node.js 20 は、サポートが終わっているため 26 に上げる

## オーナーの設定

[オーナーの関与](operations.md#オーナーの関与)の「権限」にあたるため、オーナーが設定する。

- **ブランチ保護**：main の必須チェックに、品質ゲートと `ai-review` を指定する
- **自動マージ**：リポジトリで自動マージを許可する
- **Pages**：公開元を GitHub Actions にする
- **スケジュールされたタスク**：役割ごとのタスクを作ることを承認する
