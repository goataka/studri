# 算数

小学校算数の学習の系統。系統ごとに、学年と学ぶ順に目標を並べ、前提の目標を ID で示す。

- **上位ページ**：[学習の系統](../../README.md)

## 系統

- **A 数と計算**
  - **[整数](numbers.md)**：数の数え方から、億・兆の単位、偶数と奇数、約数と倍数、概数まで
  - **[たし算とひき算](addition-subtraction.md)**：第1学年の意味から、第3学年の4けたの筆算まで
  - **[かけ算](multiplication.md)**：第2学年の意味と九九から、第6学年の分数のかけ算まで
  - **[わり算](division.md)**：第3学年の意味から、第6学年の分数のわり算まで
  - **[小数](decimals.md)**：第3学年の意味から、第4学年の小数のしくみとたし算・ひき算まで
  - **[分数](fractions.md)**：第2学年の1/2から、第5学年の通分・約分と異分母の分数のたし算・ひき算まで
  - **[式](expressions.md)**：第3学年の□を使った式から、第6学年の文字を使った式まで
- **B 図形**
  - **[平面図形](plane-figures.md)**：第1学年の形から、第6学年の対称な図形と拡大図・縮図まで
  - **[立体図形](solid-figures.md)**：第2学年の箱の形から、第5学年の角柱と円柱まで
  - **[面積と体積](area-volume.md)**：第4学年の長方形の面積から、第6学年の円の面積と角柱・円柱の体積まで
- **C 測定、変化と関係**
  - **[量と測定](measurement.md)**：第1学年の長さ比べから、第3学年の重さと時間まで
  - **[変化と関係](relations.md)**：第4学年の伴って変わる二つの数量から、第6学年の比例・反比例と比まで
- **D データの活用**
  - **[データの活用](data.md)**：第1学年の絵や図から、第6学年の代表値と起こり得る場合まで

## 範囲

- **目標の単位**：学習指導要領の各学年の内容の「知識及び技能」の項目。関連する項目は1つの目標にまとめる
- **網羅**：小学校算数の「知識及び技能」の項目は、すべていずれかの目標に含まれる
- **数学的活動**：目標には含めない
