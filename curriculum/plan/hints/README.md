## ヒントの出し方

- **1回目のまちがい**：ヒント1を出す
  - 答えは見せず、問題を言葉で問い直して、考える手がかりにする
  - 例：「1つ分はいくつかな。それがいくつ分かな」
- **2回目のまちがい**：ヒント2を出す
  - 図、数の線、具体物の絵などで、問題の場面を表して見せる
- **3回目のまちがい**：正しい答えと考え方を見せ、次の問題に進む
  - その問題はまちがえた問題として記録し、あとで同じ形の問題を出し直す
- **つまずきに合った言葉**：答えから、よくあるつまずきだと分かるときは、そのつまずきに合わせた言葉を先に出す
  - 例：「13÷4」で「2あまり5」と答えたら、「あまりは、わる数より小さいかな」
- **戻る先**：同じ目標でまちがいが続くときは、前提の目標に戻ることを勧める
  - いつ勧めるかは、[できたの基準](../mastery.md)に従う
- **言葉づかい**：責める言葉を使わず、次にすることを短く伝える。[表記の決まり](../notation.md)に従う

## 書き方

- **つまずき**：その目標でよく見られるまちがいの形。分かる範囲で、答えの形で判定できるように書く
- **ヒント1**：子どもに見せる言葉。問い直しの形で、1文で書く
- **ヒント2**：画面に出す図や絵の内容
- **戻る先**：系統の前提の目標
- **根拠**：解説に誤りやすさが書かれているときは、[解説に書かれたつまずき](commentary.md)を基にする。書かれていないときは、目標の内容から考えられるまちがいを書く
- **範囲**：作る順番の上位のアプリから書き足す。コースを作るときは、その系統のつまずきとヒントを先に書く
