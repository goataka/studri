# 目標とコースの対応表

学習の系統の目標ごとに、アプリで練習できるかを区分し、作るコースの順番を決めるための表。

- **上位ページ**：[学習の系統](../README.md)
- **関連**：[表記の決まり](notation.md)、[できたの基準](mastery.md)、[つまずきとヒント](hints/README.md)
- **目標の数**：549（◎ 283、△ 176、× 90）
- **コースがある目標**：6

## 区分

- **◎ 練習できる**：自動で採点できる問題で、目標の大部分を練習できる
- **△ 一部できる**：知識や読み取りは問題で確かめられるが、観察・実験・調べ学習・作図・表現などはアプリの外で行う
- **× 難しい**：話す、書く、話し合う、手書きで整える、本を読むなど、活動そのものが目標の中心
- **問題の形式**：その目標を練習するときに主に使う形式。× では、目標の中心となる活動を書く

## 作る順番の決め方

- **後に続く目標**：その目標を前提として、直接または間接に後に続く目標の数。小学校から中学校までのつながりを数える
- **優先度**：区分の重み（◎ 2、△ 1、× 0）×（1 ＋ 後に続く目標の数）
  - 多くの目標の土台になり、しかもアプリで練習できる目標ほど高い
- **アプリの単位**：系統ごとに、コースがない目標の優先度を合計し、合計の大きい系統から作る
