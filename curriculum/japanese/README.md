# 国語

小学校国語の学習の系統。系統ごとに、学年と学ぶ順に目標を並べ、前提の目標を ID で示す。

- **上位ページ**：[学習の系統](../README.md)

## 系統

- **[文字と書写](letters.md)**：平仮名・片仮名、漢字、送り仮名、ローマ字、書写
- **[言葉の働きときまり](words.md)**：言葉の働き、話し方、語彙、文の組み立て、敬語、音読
- **[情報の扱い方](information.md)**：情報と情報との関係、整理の仕方
- **[言語文化と読書](culture.md)**：昔話や言葉遊び、短歌・俳句、ことわざ、古典、読書
- **[話すこと・聞くこと](speaking-listening.md)**：話題を決める、構成を考える、表現を工夫する、聞く、話し合う
- **[書くこと](writing.md)**：題材を決める、構成を考える、書き表し方を工夫する、推敲する、共有する
- **[読むこと](reading.md)**：内容をとらえる、精査・解釈する、考えをもつ、共有する
