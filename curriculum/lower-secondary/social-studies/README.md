# 社会

中学校社会の学習の系統。系統ごとに、学年と学ぶ順に目標を並べ、前提の目標を ID で示す。小学校の目標を前提にするときは、小学校の系統の ID を書く。

- **上位ページ**：[学習の系統](../../README.md)

## 系統

- **[地理](geography.md)**：世界と日本の地域構成、世界の様々な地域、日本の様々な地域
- **[歴史](history.md)**：歴史との対話、近世までの日本とアジア、近現代の日本と世界
- **[公民](civics.md)**：現代社会、経済、政治、国際社会

## 範囲

- **目標の単位**：各分野の内容の「知識」（知識及び技能）の項目。関連する項目は1つの目標にまとめる
- **学年**：地理的分野と歴史的分野は第1学年及び第2学年、公民的分野は第3学年で学ぶ
- **網羅**：中学校社会の「知識」の項目は、すべていずれかの目標に含まれる
