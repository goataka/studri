# 国語

中学校国語の学習の系統。系統ごとに、学年と学ぶ順に目標を並べ、前提の目標を ID で示す。小学校の目標を前提にするときは、小学校の系統の ID を書く。

- **上位ページ**：[学習の系統](../../README.md)

## 系統

- **[漢字と書写](letters.md)**：常用漢字、楷書と行書、文字文化
- **[言葉の働きときまり](words.md)**：音声、語彙、文法、表現の技法、敬語、言葉の働き
- **[情報の扱い方](information.md)**：情報と情報との関係、整理の仕方、引用、信頼性
- **[言語文化と読書](culture.md)**：古典、共通語と方言、言葉の変化、読書
- **[話すこと・聞くこと](speaking-listening.md)**：話題の設定、構成、表現、聞くこと、話し合うこと
- **[書くこと](writing.md)**：題材の設定、構成、記述、推敲、共有
- **[読むこと](reading.md)**：構造と内容の把握、精査・解釈、考えの形成

## 範囲

- **目標の単位**：各学年の〔知識及び技能〕の項目と、〔思考力、判断力、表現力等〕の指導事項。言語活動例は目標にしない
- **網羅**：中学校国語の〔知識及び技能〕の項目と指導事項は、すべていずれかの目標に含まれる
