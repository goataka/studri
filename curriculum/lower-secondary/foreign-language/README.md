# 外国語

中学校外国語の学習の系統。系統ごとに、学年と学ぶ順に目標を並べ、前提の目標を ID で示す。小学校の目標を前提にするときは、小学校の系統の ID を書く。

- **上位ページ**：[学習の系統](../../README.md)

## 系統

- **[英語の言語材料](english-language.md)**：音声、符号、語、文、文構造、文法事項
- **[英語の五つの領域](english-skills.md)**：聞くこと、読むこと、話すこと（やり取り・発表）、書くこと

## 範囲

- **目標の単位**：英語の五つの領域別の目標と、〔知識及び技能〕の言語材料
- **学年**：中学校の英語は学年ごとの内容を示していないため、第1学年から第3学年とする
- **網羅**：中学校英語の領域別の目標と言語材料は、すべていずれかの目標に含まれる
