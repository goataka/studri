# 数学

中学校数学の学習の系統。系統ごとに、学年と学ぶ順に目標を並べ、前提の目標を ID で示す。小学校の目標を前提にするときは、小学校の系統の ID を書く。

- **上位ページ**：[学習の系統](../../README.md)

## 系統

- **[数](numbers.md)**：正の数と負の数、平方根
- **[式](expressions.md)**：文字を用いた式、整式の計算、展開と因数分解
- **[方程式](equations.md)**：一元一次方程式、連立二元一次方程式、二次方程式
- **[平面図形](plane-figures.md)**：作図と図形の移動、平行線と角、合同と証明、相似、円周角、三平方の定理
- **[空間図形](solid-figures.md)**：直線や平面の位置関係、表面積と体積、相似な立体
- **[関数](functions.md)**：比例と反比例、一次関数、関数y＝ax²
- **[データの活用](data.md)**：ヒストグラム、確率、箱ひげ図、標本調査

## 範囲

- **目標の単位**：学習指導要領の各学年の内容の「知識及び技能」の項目。関連する項目は1つの目標にまとめる
- **網羅**：中学校数学の「知識及び技能」の項目は、すべていずれかの目標に含まれる
