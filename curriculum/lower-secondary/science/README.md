# 理科

中学校理科の学習の系統。系統ごとに、学年と学ぶ順に目標を並べ、前提の目標を ID で示す。小学校の目標を前提にするときは、小学校の系統の ID を書く。

- **上位ページ**：[学習の系統](../../README.md)

## 系統

- **[エネルギー](energy.md)**：光と音、力、電流と磁界、運動とエネルギー、エネルギー資源
- **[粒子](particles.md)**：身の回りの物質、化学変化と原子・分子、化学変化とイオン
- **[生命](life.md)**：いろいろな生物、生物の体のつくりと働き、生命の連続性、自然と人間
- **[地球](earth.md)**：大地の成り立ちと変化、気象とその変化、地球と宇宙

## 範囲

- **目標の単位**：第1分野と第2分野の内容の「知識及び技能」の中項目（光と音、力の働きなど）
- **学年**：内容の(1)(2)は第1学年、(3)(4)は第2学年、(5)～(7)は第3学年で学ぶ
- **網羅**：中学校理科の「知識及び技能」の項目は、すべていずれかの目標に含まれる
